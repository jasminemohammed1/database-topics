## 📌 Folder Details

### **DDL/DML**
- DDL: Create, alter, and drop tables  
- Define constraints and relationships  
- DML: Insert, update, delete, and select data  

### **DQL (Data Query Language)**
- Functions, Joins, Ranking, Group By, Subqueries  

### **Views**
- Simple and complex views for organizing queries  

### **Stored Procedures**
- Basic procedures and procedures with parameters  

### **Triggers**
- Before/after insert, update triggers  

### **DCL (Data Control Language)**
- Granting and revoking permissions  

---

## ⚡ How to Use

1. Navigate to the folder for the topic you want.  
2. Open the `.sql` file directly on GitHub or download it.  
3. Copy the SQL commands to your database environment (MySQL, Oracle, PostgreSQL, etc.) to execute.  

---

## 📌 Naming Conventions

- Lowercase letters, no spaces  
- Underscores `_` between words  
- Optional numbering for learning order: `01`, `02`, etc.  
- Example: `dql_02_joins.sql`
